# Testes legados fora da suíte ativa

Este diretório preserva testes que importavam componentes ou rotas removidos do runtime atual do MundoAS. Eles não são incluídos pelo `vitest.config.ts` e não devem ser reativados sem reconstruir o contrato correspondente e adicionar uma implementação vigente.

Os arquivos foram movidos, não apagados, para manter rastreabilidade e evitar perda silenciosa de cobertura histórica.
